Effects

  • Colour cycle (placeholder scene carried over from the hand-written ROM)
  • Cyberpunk city parallax: five depths from per-line scrolling (B reverses, C changes speed, Start pauses)
  • Coast road: Out Run style pseudo-3D road along a Miami beach at sunset, with palette-cycled stripes and per-line curves (B reverses, C changes speed, Start pauses)
  • Moonlit waterfall: palette-cycled falling water, a shimmering plunge pool from per-line scrolling, and sprite spray (B reverses the flow, C changes speed, Start pauses)
  • AI credits: a streamed text scroll that ripples at the screen edges and settles in the middle, over a hex dump of the scene's own machine code (B reverses, C changes the wave, Start pauses)

Left/Right on the D-pad switches scene.
